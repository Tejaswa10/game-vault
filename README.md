# My Game Vault

Game Vault is a simple gaming website that showcases the games I currently play and the games I want to play.

I created this project because I wanted to make a website about something I enjoy while practicing how to build a complete website myself using HTML and CSS.

## Tech Stack

* HTML - page structure
* CSS - styling, layout, fonts, background, hover effects
* Google Fonts - custom font
* Git & GitHub - version control and repository
* GitHub Pages - hosting the demo

## Features

* Games I play section
* Games I want to play section
* Game artwork and titles
* Custom fonts and styling
* Dark gaming-themed background
* Hover animations and smooth transitions
